# Анализ маркетинговых кампаний и прогнозирование покупок спортивного магазина

Итоговый проект по направлению Data Analyst.

Проект посвящён анализу покупок и характеристик клиентов спортивного магазина: подготовке данных, восстановлению пропущенных сведений, оценке маркетинговой кампании, сегментации покупателей и прогнозированию интереса к определённому товару.

## Цель проекта

Оценить эффективность первой маркетинговой кампании, выявить различия в поведении покупателей и предложить подходы к персонализации предложений и выбору аудитории для новой кампании.

## Данные

После отбора клиентов страны с кодом 32 в анализ вошли:

- **104 437 клиентов**;
- **780 113 покупок** с положительной стоимостью.

Использовались профили покупателей, персональные коэффициенты, история покупок и списки участников первой маркетинговой кампании. Учебные данные находятся в архиве [`Data.rar`](Data.rar). Для запуска ноутбука архив нужно распаковать в папку репозитория.

## Что сделано

В рамках проекта:

- объединены данные, обработаны пропуски, названия и цвета товаров;
- построена модель бинарной классификации для восстановления пола клиентов;
- проведён A/B-анализ первой email-кампании с проверкой сопоставимости групп до её запуска;
- выполнена кластеризация покупателей методом KMeans и изучены товарные предпочтения и доля покупок со скидкой;
- построена модель склонности к покупке товара «Брюки мужские Demix» и составлен рейтинг клиентов города 1188;
- подготовлены аналитический отчёт и презентация с рекомендациями для бизнеса.

## Основные результаты

- Восстановлен пол **15 651 клиента**. Модель Random Forest достигла **F1 = 1,0** на тестовой выборке.
- В период email-кампании конверсия составила **95,81%** в тестовой группе против **100%** в контрольной, а выручка на участника — **26 628 против 22 450**. При этом группы существенно различались по покупательской активности ещё до рассылки, поэтому эффект кампании не подтверждён. Рекомендован повторный A/B-тест.
- Выделены **3 кластера** покупателей: редко покупающие, активные и чаще приобретающие товары со скидкой. Предложены отдельные подходы к работе с каждым сегментом.
- Для прогноза покупки товара «Брюки мужские Demix» получено **ROC-AUC = 0,730**. Среди верхних 10% клиентов по оценке модели частота покупки составила **4,95% против 1,35%** в среднем по тестовой выборке — в **3,65 раза выше**.
- Сформирован рейтинг **12 438 клиентов города 1188** для отбора аудитории будущей рекламной кампании.
